# 在场与缺席 (Presence and Absence)

## 作品简介

作品用两层叠加的影像呈现一个事实：

**上层小窗口**是你可以主动唤醒的记忆——长按，过去的人出现；松开，他们消失。这是你私人的、唯心的世界。

**底层背景**是永远来来往往的人群。他们不会因为你的唤醒而停留，也不会因为你的松手而改变。这是无数个与你无关的、他人的世界。

两层影像在同一画面上叠加，却永远不会相互影响。

**为什么？**

因为你的记忆是你的世界，别人的记忆是别人的世界。你不能拿着自己的记忆去概括世界，也不能要求别人活在你的记忆里。我们常常以为，自己记得很清楚的事，别人也应该理解、应该在乎。但事实是：每个人都在用自己的记忆构建属于自己的世界。你眼中的别人，其实只是你记忆中的别人；别人眼中的你，也只是他的记忆中的你。

世界不是你一个人的记忆拼成的。它是无数个无法交汇的私人世界，在同一个时空里各自流动。

**《在场与缺席》不提供答案。它只把这个结构放在你面前，让你看见：记忆是唯我的，不能以此丈量他人与世界。**

## 运行方式

### 环境要求

- Python 3.x
- 现代浏览器（支持 WebRTC 和 JavaScript）

### 启动步骤

1. 进入项目目录：
   ```
   cd gesture-demo
   ```

2. 启动 Python 服务器：
   ```
   python server.py
   ```

3. 在浏览器中打开 `index.html`

### 操作说明

| 按键 | 功能 |
|------|------|
| **鼠标点击背景视频** | 启动音频设置 |
| **A 键** | 小人向左/后退 |
| **D 键** | 小人向右/前进 |
| **红色按钮出现** | 提示可进入新的可播放区域 |
| **单击空格键** | 进入空场景 |
| **长按空格键** | 播放记忆场景（含声音） |
| **松开空格键** | 退回空场景 |
| **Alt 键** | 退出视频播放 |

## 技术说明

本项目使用 MediaPipe 进行手势识别追踪，实现用户与虚拟小人的实时交互。

## 项目结构

```
gesture-demo/
├── index.html          # 主页面
├── server.py           # Python 服务器
├── mediapipe/          # MediaPipe 手势识别模块
├── biancheng/          # 影像素材
├── bg.mp4             # 背景视频
└── line.png           # 界面资源
```
